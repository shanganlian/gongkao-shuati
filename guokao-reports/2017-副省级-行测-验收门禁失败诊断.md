## 三、`QNO_GAP` 根因：材料范围首题没有独立题号

### 3.1 原始文本证据

`guokao-reports/raw/2017年国家公务员考试《行测》真题卷（副省级）.docx.txt`：

```text
186  51、根据所给材料，回答 51~55 题。
187  技术为自身的生存和发展而战，并且有着独特的生命周期。……
188  得到那些溺爱它们的监护者（也许还包括最初的发明者）的保护和支持。……
189  填入文中画横线部分最恰当的一句是：
190  A、怀胎数月最终分娩的过程一样  B、流星划过夜空那样璀璨而耀眼  C、人类当年在月球上迈出第一步  D、人类文明酝酿以及发展的过程 52、作者举亨利·福特的例子是为了说明：
191  A、汽车产业中的工匠精神决定着工艺水平  B、技术产业的发展决定了技术应用的前景
192  C、技术推广中的额外发明比独创发明更关键  D、独创性发明本身并不一定具有核心竞争力 53、下列哪种现象可能发生在技术发展的“挑战者时期”？
```

```text
200  56、根据所给材料，回答 56~60 题。
201  我们的生活被各式各样的信息塞满挤爆，常常来不及消化，就被迫接收下一个信息，……
202  下面这个段落最适合放在文中哪个位置？
203  大脑预设人脸一定是凸出来的，不可能是凹进去的。……
204  A、①  B、②  C、③  D、④
205  57、关于认知不可穿透性，下列说法正确的是：
```

关键事实：**Q51 的实际题干是第 189 行，Q56 的实际题干是第 202 行，它们都没有题号。** 第 186/200 行只是材料范围导语，不是 Q51/Q56 的题干；第 189-190 行、第 202-204 行才是首题的题干和选项。

### 3.2 解析路径

1. `preSplitText()`（`convert-guokao.js:447-452`）会拆分“选项行尾黏连下一题”：

   ```js
   .replace(/([A-D]\s*[、.．][^\n]*?)\s+(\d{1,3})\s*[、.．]\s*(?=[\u4e00-\u9fa5“《（(【])/g, '$1\n$2、');
   ```

   因此第 190 行的 `D、…… 52、……` 会被拆成“A-D 选项行”和“52、……”两行；第 192 行的 `D、…… 53、……` 同理。当前代码据此恢复了 Q52、Q53。

2. 第 186 行先命中 `RANGE_RE`（`convert-guokao.js:549`）：

   ```js
   /(?:根据|依据|结合|阅读|所给|以下)[^。\n]{0,30}?回答\s*(?:下列)?\s*(\d{1,3})\s*(?:[～~〜—\-－至到]\s*(\d{1,3}))?\s*(?:小)?题/
   ```

   匹配结果是 `from=51, to=55`，匹配前的 `before` 为 `51、`。

3. 材料范围分支在题号分支之前（`681-700` 行，题号分支在 `720-738` 行），命中后直接 `continue`：

   ```js
   const mm = line.match(RANGE_RE);
   if (mm) {
     const from = Number(mm[1]);
     const to = mm[2] ? Number(mm[2]) : from;
     const before = line.slice(0, mm.index).trim();
     startMaterial(from, to);
     if (before) {
       if (/^[A-D]\s*[、.．]/.test(before)) appendToLast(items, before);
       else pendingMaterial.lines.push(before);
     }
     ...
     continue;
   }
   ```

   `before = "51、"` 不以 A-D 开头，于是被推进 `pendingMaterial.lines`，**不会被当作 Q51 题号创建题目对象**。第 200 行的 `56、` 同理。

4. 第 187-190 行的材料正文、Q51 题干、Q51 的 A-D 选项都处于 `pendingMaterial` 状态；由于 Q51 没有题号，题号分支无法命中，它们全部进入材料块。直到第 190 行拆出的 `52、` 才 `flushMaterial()` 并创建 Q52。第 201-204 行同理：Q56 的题干、段落、A-D 选项全部进入材料，直到第 205 行 `57、` 才 flush。
5. 因此：
   - Q51、Q56 的**题目对象不存在**；
   - 它们的文本**没有丢失**，仍保存在材料块中（这也是 Q52-55、Q57-60 的 material 字段会包含前一道题内容的原因）；
   - 答案/解析文件中有 51、56，`validatePaper` 找不到同号题目，于是报 `ANALYSIS_EXTRA 51/56`。

### 3.3 为什么基准报告是 `51-53、56`，当前只剩 `51、56`

| 版本 | 2017 副省题块数 | 缺号 | 说明 |
|---|---:|---|---|
| 基准报告 `summary.md`（17:22） | 130 | `51-53、56` | 当时 Q52、Q53 仍黏在上一行 D 选项尾部，未被拆出 |
| 当前代码 + 20:41 复现 | 133 | `51、56` | `preSplitText` 的“D 选项尾 + 下一题号”规则已拆出 Q52、Q53 |

所以 `52、53` 是**已修复项**，不是当前仍待修项。当前门禁失败范围应写成 `51、56`，而不是 `51-53、56`。

> 口径说明：130→133 的 +3 中，Q52、Q53 两项可由 `preSplitText` 规则直接确认；剩余 +1 只能确定是同一版本的其他解析边界变化，基准报告未保存逐题清单，无法逐题归因。这不影响“当前缺号为 `51、56`、当前题块为 133”的结论。

### 3.4 根因定性

- **分类**：解析器的材料范围/首题边界识别缺陷（parser boundary bug）。
- **不是**：原始 docx 缺题、题目文本丢失、答案/解析缺失。
- **影响**：Q51/Q56 无题目对象，无法进入题库；其文本被错误并入材料；答案/解析成为孤儿。
- **修复方向（建议，不在本报告实施）**：
  1. 材料范围命中后，记录 `from` 对应的“首题尚未产出”状态；
  2. 在材料块内识别“题干 + 完整 A-D 选项”的边界，把该题干作为 `from` 题（Q51/Q56）输出，而不是等下一个显式题号；
  3. 或在预处理阶段利用范围信息，把“材料正文后的第一个无号题干”补上 `from、` 前缀；
  4. 增加固定回归样例：第 189-190 行、第 202-204 行必须分别产出 Q51、Q56，且材料只保留第 187-188 行、第 201 行。

### 4.2 为什么不是 `A、/A．` 正则问题

当前选项正则为 `convert-guokao.js:435`：

```js
const OPTION_RE = /(?<![A-Za-z])([A-D])(?:\s*[、.．\)）:：]\s*|\s+)(?=[^\s])/g;
```

它同时支持 `A、`、`A.`、`A．`、`A）`、`A：` 以及老卷的空格分隔。证据：

- Q74/Q75 的 `A、15 B、10 C、8 D、6` 能正常切出 4 项，说明正则本身没有坏；
- Q65/Q69 的 `A、` 后面没有文本，只有 `[[IMG]]`，切分后得到 0 个有文本选项；
- Q73、Q76-82、Q119、Q133 的题干后直接是 `[[IMG]]`，根本没有 `A-D` 文本标签。

`isImageQuestion` 的判定（`convert-guokao.js:998-1002`）包含：

```js
const image = detectImageQuestion(parsed.stem)
  || bodyImages > 0
  || emptyImageOptions
  || blankQuestion
  || !!(material && material.text === '【图片材料】');
```

因此 Q65/Q69 由 `bodyImages > 0` 命中；Q73/Q76-82 由题干关键词（右图/问号处/展开图/立体图形等）和/或 `bodyImages > 0` 命中；Q119/Q133 主要由题干后的 `[[IMG]]`（`bodyImages > 0`）命中。12 题全部进入 `imageNums`，`OPT_NOT_4` 在 `validatePaper` 中被降级为 WARN（`1693、1674-1676`）。

### 4.3 根因定性

- **分类**：图片型选项的文本化限制（expected extraction limitation），不是选项格式解析 bug。
- **不是**：`A、`/`A．` 未被正则识别；也不是选项被错误截断。
- **影响**：这 12 题无法仅靠文本得到 4 个选项；需要图片 OCR、人工标注，或接受 WARN 并进入人工复核队列。
- **修复方向（建议）**：
  1. 不要为了消除 WARN 强行伪造 4 个文本选项；
  2. 保留 `OPT_NOT_4` WARN + `isImageQuestion` 标记，作为“图片题人工复核”队列；
  3. 如果验收要求零 WARN，应将图片题选项缺失定义为独立豁免码（如 `IMAGE_OPTION`），并设基线数量，而不是要求 `options.length === 4`；
  4. 对 Q65/Q69 可额外保留 `A-D` 空标签与图片的对应关系，便于后续 OCR/前端渲染。

## 七、修复建议（按优先级）

### P0：重新生成全量报告，冻结验收基线

当前 `summary.md` 与代码/单卷复现不一致。建议：

1. 用当前 `convert-guokao.js` 重跑 `--all --dry-run`（或正式落盘，视发布流程而定）；
2. 以新生成的 `summary.md` / `summary.json` 作为验收基线；
3. 在报告中记录脚本版本/修改时间，避免再次出现“报告早于代码”；
4. 若全量重跑成本高，至少先重跑 2017 副省级和 2017 地市级，确认 `QNO_GAP` 变化。

### P1：修复材料范围首题识别（Q51、Q56）

这是当前唯一阻断性 `QNO_GAP` 根因。建议在 `scanBlocks` 中增加“材料范围首题待产出”状态：

- 命中 `RANGE_RE` 后，记录 `pendingMaterial.from` 和 `firstQuestionEmitted=false`；
- 当材料块中出现“题干行 + 后续完整 A-D 选项块”时，把题干行作为 `from` 题输出；
- 输出后把该题绑定到当前材料，材料只保留其前面的正文；
- 处理 `51、`/`56、` 前缀时，不要把前缀当作材料正文；它是范围导语的一部分，不能单独构成题目；
- 增加回归测试：
  - 输入第 186-190 行，必须得到 Q51，且 material 不包含“填入文中画横线部分最恰当的一句是”；
  - 输入第 200-204 行，必须得到 Q56，且 material 不包含“下面这个段落最适合放在文中哪个位置？”；
  - Q52、Q53 仍必须从 D 选项尾部拆出（防止回归）。

### P2：保留并加固 Q52/Q53 的拆题规则

当前 `preSplitText` 的 `D、…… 52、` 规则已经生效。建议：

- 增加单元测试覆盖“选项行尾 + 下一题号”的两种形态（`52、` 和 `53、`）；
- 确认该规则不会误切材料中的“第 52、53 条”之类数字；
- 在报告中把 52/53 标记为“已修复/回归通过”，不要继续列为当前失败。

### P3：图片题选项按 WARN 管理，不要伪造四项

- 12 处 `OPT_NOT_4` 全部是图片题，正则修复不会让它们变成 4 个文本选项；
- 建议保留 `isImageQuestion` 与 WARN，建立图片题人工复核清单；
- 若验收要求零 WARN，新增 `IMAGE_OPTION` 豁免码并设基线，而不是把图片题强行算作文本题；
- Q65/Q69 可保留 `A-D` 标签与图片占位，Q73/Q76-82/Q119/Q133 可保留 `[[IMG]]` 顺序，供前端/OCR 使用。

### P4：处理 Q60 的答案映射与重复 issue

- Q60 `MISSING_ANSWER` 出现两次，建议在 `validatePaper` 输出层按 `(code,num,id,detail)` 去重；
- 单独检查 Q60 的答案块是否被 Q56-Q59 的材料/解析切分影响；
- 该问题不属于 `QNO_GAP`/`OPT_NOT_4`，但会影响“ERROR=0”的整体验收。

### P5：覆盖缺口单独立项

- 2026 年无源文件：需要补源数据，不能靠解析器修复；
- 2008 申论 0 题：检查该年 docx 是否只有材料/答案而无题目，或解析规则不匹配；
- 2021 副省行测、2022 地市行测答案 0%：优先检查 `ANSWER_SOURCE_EMPTY`，属于答案源文件/配对问题；
- 2025 三套申论 0 答案：检查答案文件命名与配对；
- 这些缺口不应混入 2017 两个门禁的根因分析。
