1. 联网核对原卷（国考真题公开可查），补全缺失选项的**原文文本**，填入 `options` 数组对应位置并保持 A/B/C/D 顺序。
2. 若原题为图片选项（公式/图形），不要臆造文本：补 `isImageQuestion: true` 并在下表状态列写 `图片题-需图`。
3. 若多方核对仍找不到原题：状态列写 `missing`，并在 `PROGRESS.md` 的 known-losses 段记账，**不要**补占位文本。
4. 回填后必须重跑 `node scripts/validate-questions.cjs --dir public/data/questions-v2`，E05/E06 计数应同步下降。
5. 注意：个别题干的表格/材料里残留了缺失选项的文字（如 `gk-2008-未标注-125` 题干中的「A年印刷量减少的企业数 11 11」），
   回填时先与题干交叉核对，这类题不算“无源可查”。
6. **必须双写（防止重转丢失）**：除改 `public/data/questions-v2/` 分片外，同一份修改必须落到可重放的源头，二选一：
   - 改 `source-data` 源文档（下次 `node scripts/convert-guokao.js --all` 自动带出）；或
   - 新增幂等 patch 脚本 `scripts/patches/<名称>.cjs`（读分片 → 按题目 ID 补 `options` → 写回，重复执行结果一致），并在 `PROGRESS.md` 记一行执行命令。
   **只改分片的提交不予接受**：重转后修改会被静默回退。
7. 顺序：`node scripts/convert-guokao.js --all`（全量重建 v2）→ 回填/patch → 重跑校验 → publish 合并；
   不要在校验或合并之后才跑重转。
