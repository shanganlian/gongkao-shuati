## 7. 执行计划

```powershell
node scripts/publish-merge-provinces.cjs --province 海南 --drop-uncovered          # dry-run（本报告）
node scripts/publish-merge-provinces.cjs --province 海南 --apply --drop-uncovered  # 审核通过后执行
node scripts/verify-question-loading.cjs
npm run build
```

- `--apply` 执行顺序：删除多余旧海南分片 → 复制 13 个新分片（映射为 `provincial-海南-*`）→ 全量重建 `index.json` / `idMap.json`。
- `--apply` 自检：被替换旧分片清零、分片数 / 题目数与计划一致、index 精确覆盖、idMap 覆盖全部 ID；任一失败即中止。
- 备份：脚本不生成 publish 备份；回滚基线为 apply 前的 git HEAD（执行前先记录 `git rev-parse HEAD`），旧分片与 `index.json` / `idMap.json` 均在版本库中。
- 失败回滚：`git checkout <apply 前 HEAD> -- public/data/questions/` 后重新执行 dry-run。
- 脚本不执行 `git push`；如需发布，人工确认暂存清单后提交并推送。

> 当前为 dry-run：未改动 `public/data/questions/` 中任何题目数据。确认本报告后再加 `--apply`。
