## 2. 前端兜底审计

### 2.1 占位卡的触发条件（源码事实）

`src/components/MissingFigurePlaceholder.tsx`（非 compact：标题「本题配图缺失」+ 说明 + 「跳过本题」；compact：单行提示 + 答案）。**4 处调用，条件完全相同**：

| 位置 | 场景 | 条件 | 形态 |
|---|---|---|---|
| `PracticeArena.tsx:1410` | 练习主区 | `currentQ.isImageQuestion && !currentQ.imageUrl` | 非 compact，`onSkip` 仅在 `filteredQuestions.length > 1` 时传入 |
| `PracticeArena.tsx:771` | 套卷逐题列表 | `q.isImageQuestion && !q.imageUrl` | compact，无跳过 |
| `PracticeArena.tsx:990` | 错题本列表 | `q.isImageQuestion && !q.imageUrl` | compact，无跳过 |
| `PracticeArena.tsx:1069` | 复习模式 | `currentReviewQ.isImageQuestion && !currentReviewQ.imageUrl` | compact，无跳过 |

要点：

- 判定只看 `isImageQuestion`，**不看 subModule**：资料分析图表题同样走这一分支。
- 优先级更高的两个分支会"截断"渲染：
  1. `isAbnormalQuestion(q)` → `AbnormalQuestionPlaceholder`（"本题数据整理中"），在 `:763 / :984 / :1400`；判定 = `isAbnormal` 标记 / 选项 key 重复 / 题干或选项含题号串 / E10 / E09。
  2. `filterValidQuestions`（`useQuestions.ts:103、138`，`PracticeArena.tsx:753、970`）：`getInvalidReason` 非空则**题目直接不进池**（题干空；非图片题选项 <2 或有空文本）。**图片题允许无选项**（`isValidQuestion` 对 `isImageQuestion` 直接返回 true）。
- 选项区（`:1425`）：`options.length > 0` 才渲染按钮；否则 `isImageQuestion ? null : "主观题无固定选项"`。→ 图推题 `options=[]` 时选项区**什么都不渲染**。
- 「选项图形从左至右依次为 A、B、C、D」提示（`:1420 / :776 / :1074`）：`hasFigureOnlyOptions` 要求 **有 imageUrl** + 4 项 + key 严格 `ABCD` + 四项 text 全空。→ **无图题永远不显示这条提示**。

### 2.2 2011–2025 图推"页面上题目和选项均无"的成因（逐条）

数据事实（国考 2011–2025 图推 316 题）：

1. **图形本体不存在**：316 题 `imageUrl` 全空 → `QuestionFigure` 返回 null；图形只存在于缺失的图片里，题干文字不含图形。
2. **题干只剩通用指令**：147 题是「从所给的四个选项中，选择最合适的一个填入问号处…」，其余 159 题是分类题指令（「把下面的六个图形分为两类…」）或数量/资料题题干（如 `gk-2024-副省级-71` 面积比、`gk-2025-副省级-78/80` 面积/容器）。→ 页面顶部只有一句"操作说明"，不是题目内容。
3. **选项区大面积空**：127 题 `options=[]` → 选项区渲染 `null`；另有 42 题选项文本就是 `A/B/C/D`（2024×21、2025×21）、21 题四项都是"如上图所示"（2022）→ 有 4 个按钮但点开无内容。剩余 126 题有真实文本选项（分类题组合、数量/资料数值），但题干图形仍缺。
4. **它们确实进了缺图占位分支**：315/316 题满足 `isImageQuestion && !imageUrl`，练习区应出现黄色「本题配图缺失（参考答案：X）… 可先跳过本题」卡片；套卷/错题/复习为 compact 单行提示。

→ 所以"题目和选项均无"不是"没进占位分支"，而是：**唯一的题面（图）+ 真实的选项都不存在，页面上只剩一句通用指令 + 一张缺图卡**（练习区还能看到参考答案）。

**没进占位卡分支的只有 1 题**：`gk-2025-副省级-80`（无图、无 `isImageQuestion` 标记、有 4 个数值选项；实际是"容器注水"数量题，被标成图形推理，`subModule_confidence=low`）。它既没有图也没有占位卡，只剩题干 + 4 个文本选项。

**如果页面上连缺图卡都看不到**，数据层只有三种可能（其余都已被排除）：

| 可能 | 事实核对 |
|---|---|
| 运行的前端构建早于 2026-11-16 | 占位卡是 11-16 配图批次引入；`8554212` 尚未 push，线上包版本需另外核对 |
| 题目被 `filterValidQuestions` 过滤（题干空） | 国考 2011–2025 图推题干空 = **0**，不成立 |
| 选了「图形推理」二级分类，但题目 `subModule_confidence=low` 被 `subModMatch` 排除 | 国考图推共 **5 题** low：`gk-2005-一卷-60`、`gk-2005-二卷-60`、`gk-2017-副省级-119`、`gk-2017-副省级-133`、`gk-2025-副省级-80`；这 5 题在"图形推理"筛选下不出现（选"判断推理/全部"仍可见）。`src/data/submoduleCounts.json` 的 `national-none-panduan.图形推理 = 445` 正是 450 − 5 |

省考同型且更彻底：4,970 题 **0 张图**（0% 有 imageUrl），3,756 题 `options=[]`，2011–2025 全部无图。

### 3.2 抽样时额外发现（与本次 stem 清理、配图批次直接相关）

1. **29 题 stem 整行就是 `"A B C D"`**（2000 卷 10 + 2001 卷 9 + 2003-A 卷 9 + `gk-2006-一卷-52`，与 stem 清理 dry-run 的 29 处命中完全对应）。
   ⚠️ 风险：若把字母行**删掉**，这 29 题 stem 会变空串，`getInvalidReason` 判「题干为空」→ `filterValidQuestions` 直接过滤 → **这 29 题会从练习池 / 套卷 / 错题本整体消失**（比现在显示 `"A B C D"` 更糟）。
   现方案（2026-11-21 改）：整题只有字母行的，把字母行**替换**为通用题干「请从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定的规律性：」；题干另有正文的只删字母行、正文逐字保留。
   dry-run 结果（`node scripts/clean-figure-stem-letters.cjs --dry-run`）：**29 题替换 / 0 题只删行 / 未命中 83 题 / 空题干 0 题**，未 apply。
   全量口径（`--scope figures`）另有：**72 题替换、776 题只删行**（国考侧含 `gk-2003-A卷-22`、`gk-2006-一卷-55`），只作盘点、不在本次范围。
2. **选项字母标注不统一**：2002-A 的选项图带 A–D 字母；2001 的 4 个选项图**没有**字母；2003-A 的 `17/19` 是「题干 4 图 + 选项 4 图」同图两栏且无字母（`24` 有 A–D 字母）。前端「左→右 = A/B/C/D」提示只要求"有图 + 4 项 + key ABCD + text 全空"，因此 2000 / 2001 / 2003-A 共 29 题会显示该提示，但图上没有字母可对齐。
3. **解析文本被插入断行**：2000–2010 国考图推共 **23 题**（2001×4、2003-A×7、2004×1、2005×1、2006×2、2007×3、2008×1、2009×1、2010×3），如 `gk-2001-79`「…把小矩形向右平行移动一段距\n\n离后…」、`gk-2003-A卷-16`「…可知选项 A 正\n\n确。」、`gk-2010-未标注-64`「…A 选项中\n\n顶面的斜线方向错误」；2021 年起的 `解析\n\n第一步` 是正常分段，不计入。逐题清单见 `guokao-reports/题干质量待修清单.md` C1。
4. **图片与题号错位 / 混题**：`gk-2002-B-96` 的图内含两题（点阵格题 + 叠加题）；`gk-2002-B-99.webp` 是 396×846 整页扫描（非单题图）。这两题在页面上会显示"无关图形"。
5. **模块误标**：`gk-2024-副省级-71`（面积比）、`gk-2025-副省级-78/80`（面积/容器）是数量题标成图形推理；其中 2 题 `isImageQuestion=true` 且无图 → 显示"缺图"占位，会误导用户。
6. **2003-B 整节（16–25）无题干来源**：`options=[]`、`imageUrl` 空、stem 为统一占位句；`guokao-reports/图形推理配图补全-2026-11-16.md` 已记录"需换来源（原卷 PDF/题库）先补题干再补图"。

### 核对方法（可复跑）

1. 全库盘点：遍历 `public/data/questions/*.json`（跳过 `index/idMap/questions.json`），筛 `subModule === "图形推理"`；年份从 `id` 解析（`gk-2002-A卷-86` → 2002）。
2. 分支判定直接复用前端逻辑：`getInvalidReason(q)`、`isAbnormalQuestion(q)`（`src/lib/questionValidation.ts`），避免口径漂移。
3. 抽样核对：把 `imageUrl` 指向的图片按 3–8 倍放大（`sharp`，`kernel: lanczos3`）后逐图判读；跨年、跨卷抽 3 题/卷。
4. 本次盘点的中间产物（脚本、放大图、逐题明细）已在报告定稿后清理，未提交；如需复跑可按上述三步重建。
