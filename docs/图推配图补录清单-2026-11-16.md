## 三、后续操作

```
# 1) 逐题放行：对已抽出、只是同卷还有缺图的卷，只落盘名单内的题（其余保持 error）
node scripts/extract-figure-images.cjs --year 2002 --paper B卷 --docx B卷 --tag B --apply --only 96,97,98,104,105
node scripts/apply-figure-image-urls.cjs --report scripts/out/figure-extract-2002-B.report.json --apply

# 2) 人工补图后写回：先做 <年>-<卷>-<题号> 命名的 webp（≤100KB），再
node scripts/apply-figure-image-urls.cjs --map <清单.json> --apply

# 3) 原图超 100KB：先转 webp（sharp，白名单 3 题），再按 report 写回
node scripts/convert-oversize-figure-images.cjs --apply
```

> 说明：`scripts/out/figure-extract-*.report.json` 每次重跑都会覆盖，只有当前卷的结果可信；
> 本清单每次重跑都按题库 imageUrl + 最新报告重算，可随时再执行 `node scripts/report-figure-gaps.cjs` 刷新。
